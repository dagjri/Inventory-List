# 持ってるやつ一覧(動画リスト管理アプリ)

Notionで管理していた動画リストを、**ブラウザ上で追加・編集・削除できる管理アプリ**にしたものです。GitHub Pagesに置けばURLを開くだけで使えます(サーバー・データベース不要の静的サイト)。

## できること

- 🔍 **検索・絞り込み** — キーワード検索 + グループ/個人/ジャンル/ステータスでのフィルタ
- ✏️ **追加・編集・削除** — ブラウザ上のフォームから操作(削除は誤操作防止の2段階確認)
- 🏷️ **ステータス管理** — 「未視聴/視聴済み/お気に入り」+ 自由なタグ
- 💾 **自動保存** — 変更はすぐブラウザ内(localStorage)に保存される
- 📤 **バックアップ** — JSON/YAMLでの書き出し・読み込みに対応(端末間の移動もこれで)
- 📱 スマホ対応(細い画面ではカード表示)

## データの保存場所(大事)

このアプリのデータは **ブラウザの中(localStorage)** に保存されます。

- サーバーには保存されません。GitHub Pagesは「アプリ本体」を配っているだけです
- そのためデータは **端末・ブラウザごとに独立** します(スマホで追加した項目はPCには自動では出てきません)
- **バックアップ・移動**:「JSON書き出し」でファイル化 → 別の端末・ブラウザで「ファイル読み込み」
- 初期データは `docs/data/videos.yml`(94件)。ブラウザの保存データがなければ、この内容で表示されます

## 使い方

| 操作 | やり方 |
|---|---|
| 追加 | 「＋ 追加」→ フォーム入力 → 保存 |
| 編集 | 一覧の行をクリック →「編集」 |
| 削除 | 詳細画面の「削除」を2回押す(誤操作防止) |
| 検索 | キーワード欄に入力(タイトル・メモ・出演者などを横断検索) |
| 絞り込み | グループ/個人/ジャンル/ステータスのプルダウンを組み合わせ |
| 並べ替え | 追加順 / 名前(あ→ん) |
| バックアップ | 「JSON書き出し」でファイル保存 |
| 復元・移設 | 「ファイル読み込み」でJSON(またはYAML)を選択 → 確認画面で「実行」 |
| 初期化 | フッターの「初期データに戻す」(videos.ymlの状態に戻る) |

入力欄はカンマ(,)・読点(、)区切りで複数指定できます(例: `西畑大吾, 大西流星`)。入力欄では、これまで使った値が候補として表示されます。

## GitHubにアップロードする(初回のみ)

### A. ブラウザだけで完了する方法

1. GitHubにログイン → 右上の **+** → **New repository**
2. Repository name を `video-list` などにして **Create repository**(Public推奨)
3. リポジトリ画面の **「uploading an existing file」** リンクをクリック
4. 解凍した `video-list` フォルダの中身(`docs` フォルダと `README.md`)をドラッグ&ドロップ
5. **Commit changes** を押して完了

※ブラウザのアップロードはフォルダ構造を保てない場合があります。確実なのは次のB(デスクトップアプリ)です。

### B. GitHub Desktopを使う方法(おすすめ)

1. [GitHub Desktop](https://desktop.github.com/) をインストールしてサインイン
2. **File → Add Local Repository** → この `video-list` フォルダを指定(「not a repository」と出たら **Create a Repository** を選択)
3. **Publish repository** を押すとGitHubにアップロードされる

## サイトを公開する(GitHub Pages)

1. GitHubのリポジトリページで **Settings → Pages**(左メニュー)
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / **Folder**: **`/docs`** を選んで **Save**
4. 1〜2分で `https://(ユーザー名).github.io/video-list/` として公開される

公開後はURLを開くだけで追加・編集ができます。スマホのホーム画面に追加しておくと自分専用アプリのように使えます。

## 初期データ(videos.yml)について

- `docs/data/videos.yml` はNotionから移行した94件の初期データです
- アプリ内の「YAML書き出し」を押すと、現在のデータをこの形式で書き出せます。それを `docs/data/videos.yml` としてリポジトリに上げ直せば、初期データも最新化されます(任意)
- YAMLの1項目は「- 名前:」で始まるかたまり。項目名(名前/出演者/グループ/個人/ジャンル/画質/メモ/動画URL/ステータス/タグ)はそのままにしてください

## うまくいかないとき

- **データが消えた気がする** → 別のブラウザ・端末を見ていませんか?データはブラウザごとに独立します。JSON書き出しファイルがあれば「ファイル読み込み」で戻せます
- **サイトがエラー表示になる** → `docs/data/videos.yml` のインデントが崩れていないか確認(全角スペースで下げていないか)
- **変更が反映されない** → ブラウザを再読み込み。GitHub Pagesの更新は数十秒〜数分かかることがあります
- **やり直したい** → フッターの「初期データに戻す」
